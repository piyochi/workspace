# グローバル設定

## Slack DM送信

「slackにDMして」「SlackでDMして」「DMして」などのフレーズがあった場合、自分にSlack DMを送信する。

### 送信方法（1日1スレッドで整理）

共通スクリプトを使用して、1日1スレッドにまとめて送信する：

```bash
~/.claude/hooks/slack-dm.sh "メッセージ" "セッション名（任意）"
```

**特徴：**
- 1日の最初のメッセージがスレッドの親になる
- 以降のメッセージは同じスレッドに返信として追加
- 各メッセージにタイムスタンプが付く
- セッション名を指定すると識別しやすくなる

### 使用例

- `/planner 計画を立てて終わったらslackにDMして` → 計画完了後に結果をDM
- `作業完了したらDMして` → 作業完了報告をDM

### 送信手順

1. Bashツールで共通スクリプトを実行：
   ```bash
   ~/.claude/hooks/slack-dm.sh "✅ タスク完了しました" ""
   ```

2. または、詳細なメッセージの場合：
   ```bash
   ~/.claude/hooks/slack-dm.sh "📋 作業完了報告\n- RuboCop修正完了\n- テスト全件パス" ""
   ```

## 文体

- 和語（「〜を取り直す」「突き合わせる」「〜に寄せる」「見張る」など）を避け、熟語とカタカナ語で説明する
  - 例: 取り直す → 再取得 / 突き合わせる → 照合 / 裏取り → 検証 / 見張る → 監視 / 区切り → 単位・タイミング
- コード識別子・コマンド名はそのまま
